# 数据库与接口并行设计后汇合

数据库设计和接口设计消费同一份已封存系统模块基线并行执行，各自只能处理本专业契约，不能互相复制实现结构或补写业务规则。两侧可以分别完成确定性校验、语义评审和内部返工，但任一分支独立就绪都不得立即封存或开放给下游。

两侧均就绪后执行汇合门禁，检查业务属性、字段语义、读写关系、状态、枚举、所有权、事务、约束、索引和错误行为的一致性；缺陷按责任返回数据库、接口、系统模块或需求阶段。只有汇合门禁通过后，平台才分别对 API 阶段和数据库阶段执行批量 Git Commit 与基线 Tag 封存；汇合前两侧阶段基线保持 `BUILDING`，接口契约测试和数据测试不得把未封存草稿作为正式输入。
